# Discovery and commercial test

## Audience and promise

Solana developers and AI agents checking whether a wallet has empty token accounts worth further review. The deliverable is a clear, source-backed gross estimate and optional details; it is not financial advice or a guarantee that any wallet or token is safe. The project is POTIFY-branded and links to the existing Project Reclaim source and POTIFY website.

## Discovery channels

1. Publish source in a dedicated POTIFY GitHub repository when repository creation access is available. Link to the existing Reclaim repository and the POTIFY public build catalog with precise implementation status.
2. After stable hosting and namespace ownership are established, prepare a standards-compliant MCP registry entry. A listing does not cause every AI agent to discover or choose the tool.
3. After the real x402 route, mainnet payment flow and wallet recovery are verified, investigate a facilitator's resource directory and appropriate agent catalogs. Confirm listing requirements and receipts rather than assuming inclusion.
4. Consider an Apify listing for additional discovery only if its separate payout model fits the founder's goal. Its platform payout is not automatically a direct Solana-wallet payout. Do not duplicate charges across channels.

## Pricing and measurement

The local devnet detail challenge uses a hypothetical $0.002 per call; it is not a live price or proven profitable. Measure actual facilitator, RPC and hosting costs, including free-tier exhaustion and failed requests, before choosing a public price. Compare equivalent products and return sizes; do not claim a lower price than a competitor without checking current terms.

Track real registry/listing acceptance; distinct successful agent calls; source errors; paid requests, refunds and confirmed receipts; observed average cost; and click-through to Project Reclaim. Proposed milestones: 5 independent tool invocations, then 1 verified paid test on a reviewed launch. These are targets, not completed outcomes or income forecasts.
